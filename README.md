# 🛡️ Security+ بالعربي — دليلك الذكي لإتقان CompTIA Security+ (SY0-601)

موقع ويب تفاعلي بالعربية يقدّم **تحليلاً فعلياً لخمس قوائم يوتيوب** لشرح منهج CompTIA Security+ (SY0-601):
**260 فيديو (137 ساعة)** تم فحصها وتصنيفها، مع اختيار **أفضل درس لكل موضوع من الفصول الـ21**، وتوثيق سبب كل اختيار واستبعاد، وترتيب أولويات واضح:

| الأولوية | المعنى | العدد |
|---------|--------|-------|
| ⭐ **مهم** | المسار الأساسي — ابدأ من هنا | 22 فيديو (نحو 19 ساعة) |
| 🟡 **متوسط** | معامل وتطبيق يدعم الأساسيات | 33 فيديو (نحو 16 ساعة) |
| 🟣 **فيما بعد** | مراجع وبدائل عند الحاجة | 198 فيديو |
| ⚫ **غير مهم** | مكرر أو ضعيف القيمة — استُبعد | 7 فيديوهات |

## ✨ المميزات

- 🗺️ **خطة الدراسة المثالية**: 21 فصلاً بترتيب الكتاب الرسمي، لكل فصل أفضل فيديو مختار + سبب الاختيار + النقاط الأساسية + مقارنة المصادر المتشابهة
- 📊 **تحليل القوائم الخمس**: كل فيديو من الـ260 مصنف مع سببه — ما اختير وما استُبعد ولماذا (صفحة مستقلة لكل قائمة)
- 🗓️ **جدول زمني مقترح**: خطة 5 أسابيع (~45 دقيقة يومياً) + حقائق الامتحان الرسمية
- 🔍 **فلاتر وبحث**: حسب الأولوية أو النطاق (D1–D5) أو نص حر
- ✅ **تتبع التقدم**: علّم كل فصل كمنجز — يُحفظ تلقائياً في متصفحك
- 🌗 **وضع ليلي/نهاري** بألوان مريحة (تدرجات الأزرق والأخضر)
- 📱 **تصميم متجاوب بالكامل**: هاتف، جهاز لوحي، حاسوب (RTL عربي أصيل)
- ⚡ **بدون أي اعتماديات بناء**: HTML + Tailwind (CDN) + JavaScript خالص — لا يحتاج تثبيت شيء

## 🚀 التشغيل محلياً

لا يحتاج المشروع أي تثبيت — افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
# بأي طريقة تفضلها:
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## 📤 النشر على GitHub

1. أنشئ مستودعاً جديداً على [github.com/new](https://github.com/new) وسمِّه مثلاً `security-plus-arabic-hub`
2. ارفع ملفات المشروع:

```bash
git init
git add .
git commit -m "إطلاق دليل Security+ بالعربي"
git branch -M main
git remote add origin https://github.com/USERNAME/security-plus-arabic-hub.git
git push -u origin main
```

**لتفعيل GitHub Pages** (استضافة مجانية):
- Settings ← Pages ← Under "Build and deployment" ← Source: `Deploy from a branch` ← Branch: `main` / `/ (root)` ← Save
- بعد دقائق سيكون موقعك على: `https://USERNAME.github.io/security-plus-arabic-hub/`

## ▲ النشر على Vercel

**الطريقة الأولى (الأسرع):**
1. ارفع المشروع على GitHub (كما أعلاه)
2. افتح [vercel.com/new](https://vercel.com/new) وسجّل الدخول بحساب GitHub
3. اختر المستودع ← اضغط **Deploy** (بدون أي إعدادات — Vercel يكتشف الموقع الثابت تلقائياً)
4. ستحصل على رابط مباشر مثل `security-plus-arabic-hub.vercel.app`

**الطريقة الثانية (Vercel CLI):**

```bash
npm i -g vercel
vercel          # أول مرة للربط
vercel --prod   # للنشر النهائي
```

## ✏️ تخصيص المحتوى

كل البيانات في ملف واحد: `assets/js/data.js` — عدّل ما تشاء ثم أعد الرفع:

- **إضافة فيديو/تعديل حالة**: عدّل مصفوفة `videos` داخل القائمة المعنية (الحالات: `imp` / `med` / `later` / `skip`)
- **تعديل خطة الفصول**: مصفوفة `chapters`
- **الجدول الزمني**: مصفوفة `schedule`
- تقدّمك الشخصي يُخزن محلياً في متصفحك (`localStorage`) ولا يُرسل لأي مكان
